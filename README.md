# ai2030-assets

Images that the VRChat world 「分岐点 — The Branch Point」 downloads at runtime (VRCImageDownloader).

- `atlas/<lang>/<station>_<n>.png` — translated station posters, packed into 2048×2048 sheets (en / zh-CN / zh-TW / ko). The Japanese originals are built into the world.

All posters, notices and advertisements depict fictional organisations and events.
